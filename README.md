# DevOps Practice Project 

A beginner-friendly DevOps practice project built with Node.js, Docker, and Docker Compose.

## Technologies Used
- Node.js
- Docker
- Docker Compose
- Git & GitHub
- Nginx (Reverse Proxy)

## What I Learned
- Building and running a Node.js application
- Creating a Docker image and running containers
- Managing the application with Docker Compose
- Using Git for version control and GitHub for code hosting

This project is part of my hands-on journey to learning DevOps, one step at a time.
